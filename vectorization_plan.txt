# Codebase Optimization Plan

## Overview

The codebase uses `to_dicts()` + row iteration in **30+ locations** across 8 files. This is a significant anti-pattern for Polars, which is designed for vectorized operations.

---

## Phase 1: High-Impact Vectorization (Critical Path)

### 1.1 [src/core/bayesian_risk.py](cci:7://file:///Users/mikey/HomeWorks/homelab-repos/cves_analytics/src/core/bayesian_risk.py:0:0-0:0) - [assess_vulnerabilities_bayesian()](cci:1://file:///Users/mikey/HomeWorks/homelab-repos/cves_analytics/src/core/bayesian_risk.py:1334:0-1442:13)
**Lines**: 1335-1443 | **Impact**: HIGH | **Effort**: HIGH

**Current**: Row-by-row iteration with complex object instantiation
```python
results = [assess_row(row) for row in df.to_dicts()]
```

**Proposed**:
- Pre-extract CVSS vector components into columns using vectorized parsing
- Pre-compute likelihood ratios as columns using `pl.when().then().otherwise()`
- Use `pl.struct()` for complex multi-column operations
- Keep only the final Bayesian calculation as row-wise (unavoidable due to math complexity)

**Estimated speedup**: 3-5x for large datasets
